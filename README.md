# todolist_project
A simple Python To-Do List app created by following a full project workflow.
This repository contains a beginner-friendly Python To-Do List application, created while learning how to build and improve a small project using a full development process from idea to final version.

# Project Overview
This project is a simple console-based To-Do List app that allows users to:
1- Add tasks
2- View tasks
3- Remove tasks
4- Exit the program

The app was built step by step, starting from the planning phase and improving through iterations.

# Development Lifecycle
This project followed a simplified software development process:
1- Business Requirements & Logic
2- Started with the idea of a basic task management tool.

Still in the process of learning how to define and understand business requirements and logic more clearly.

# Planning Phase

Used Miro to map the main structure and user flow of the app.

# Execution & Testing

Developed the initial version of the code with core functionality.

Tested for basic interactions and improved based on the results.

# Adjustments & Improvements

Updated the code to handle edge cases (like trying to remove a task that doesn't exist).

Improved task display formatting for better user readability.
